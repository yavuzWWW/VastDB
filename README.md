# VastDB — Clean Installation

This package contains the **original VastDB code unchanged** with the database tables/data cleared.

Choose your language:

- [English documentation](docs/README_EN.md)
- [Türkçe dokümantasyon](docs/README_TR.md)

## What was cleaned

The previous table folders and table data were removed. `data/tables.vast` is empty.

`data/info.vast` was intentionally preserved because the current VastDB code uses it for the admin username, admin password hash, and admin access-key hash.

## Important

Before putting this on a public server, read the **Security / current limitations** section in the documentation.
